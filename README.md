# Зал — тренировки

Приложение для телефона (PWA) под наш план тренировок: что делать сегодня, с каким весом делали в прошлый раз,
как делать упражнение и календарь, где можно перенести тренировку. Работает без интернета, все записи хранятся на
самом телефоне: у каждого свои.

Открыть: https://ascon5.github.io/gym/

## Как поставить на телефон

- **iPhone**: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Android (Redmi и другие)**: открыть ссылку в Chrome → ⋮ → «Установить приложение» или «Добавить на главный экран».

При первом запуске приложение спросит, кто тренируется: Ихтияр, Асадбек, Джамшид или другое имя.

## Как устроено расписание

Четыре тренировки идут по кругу через день: Верх А → Низ А → Верх Б → Низ Б (от 22.11.2026, это был Верх Б).
Начал тренировку — следующая ставится через день после неё. «Перенести» двигает следующую тренировку на другой день,
а все дальнейшие сдвигаются вместе с ней, порядок не ломается. Если день пропустили и ничего не нажали, тренировка
просто переезжает на сегодня.

## На тренировке

- В каждом подходе уже стоит прошлый вес и повторы — сделал, поправил цифру, если надо, и нажал галочку.
- Рабочий вес обновляется сам по отмеченным подходам, его видно в плане и на главной.
- Подсказка «пора прибавить вес» — по правилам из плана: база — две тренировки подряд на верхнюю границу повторов,
  изоляция — одна.
- Таймер отдыха включается только кнопкой ⏱ у упражнения.
- Упражнения «с 3-й недели» и «с 5-й» показаны отдельно, неделя считается от даты начала программы (меняется во
  вкладке «Ещё»).

## Файлы

`plan.js` — план (дни, упражнения, подходы, кардио, правила), техника упражнений; `app.js` — логика; `app.css` —
оформление; `sw.js` — офлайн-кэш (после изменения файлов поднять `VERSION`); `art/` — рисунки движения
(Everkinetic, CC BY-SA 4.0); `m/` — схема мышц (wger, CC BY-SA); `manifest.webmanifest`, `icon-*.png` — установка.
